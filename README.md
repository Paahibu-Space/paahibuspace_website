# paahibuspace_website


## Folder Structure

-  **/assets**
   - Contains the assets of the website

## Subfolders

### /css

    - Contains the custom css styles

### /images
    - Contains the project images

### /js
    - Contains the project defined js files

### /vendor
    - Contains the the project vendor files including bootstrap, aos, bootstrap-icons, glightbox, isotope-layout
